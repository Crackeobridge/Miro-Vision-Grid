## Features

- Advanced board templates (Mind Maps, Kanban, User Story Mapping, Retrospectives) optimized for rapid brainstorming, agile planning, and professional workshop facilitation.
- Workflow automation scripts (Miro REST API, Webhooks) to streamline repetitive card creation, automated Jira/Asana sync, and cross-board data aggregation tasks.
- Custom widget, sticker, and icon pack presets for enhanced visual consistency and rapid diagramming across distributed teams.
- Quick-switch macros and custom keyboard shortcut profiles for seamless navigation between the toolbar, layers, presentation mode, and developer console.
- Pre-configured voting, feedback, and icebreaker templates with automated timer routines, anonymous polling, and results clustering.
- Comprehensive documentation and step-by-step setup guides for all included tools, `.rtb` (Miro board template) imports, and modules.
- Integration examples and bridge scripts for third-party productivity ecosystems (e.g., Slack, Microsoft Teams, Jira, Figma, Notion).
- System resource optimization configs for faster rendering of massive boards, reduced browser memory footprint, and optimized handling of high-resolution embedded media.
- Ready-to-use facilitation and moderation routines with automated participant muting, spotlighting, and breakout room assignment setups.

## Requirements

- Windows 10/11 (or macOS / Linux)
- Modern web browser (Chrome, Edge, Safari, Firefox) or installed Miro Desktop App
- Active Miro account (Team or Enterprise plan recommended for advanced API access, custom templates, and SSO features)

## Usage

To utilize the included resources, download the package using the link above and extract the contents to a local directory. Run the provided setup utility (`Setup.exe` or `Install.ps1`) to integrate the custom board templates, widget packs, and automation scripts directly into your Miro workspace via the native import tools or Miro Developer Platform. Follow the on-screen prompts to complete the configuration process. For detailed customization and advanced API automation usage, refer to the `GUIDE.md` file included in the archive.
